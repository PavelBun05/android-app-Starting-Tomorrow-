# Starting tomorrow — Android

Проект для Android Studio. Java + Android Views + SQLite. Приложение работает без интернета, все данные хранятся на устройстве.

## Как открыть проект

1. Распакуй архив в папку **без кириллицы** в пути, например `C:\AndroidProjects\StartingTomorrow`.
2. Открой эту папку в Android Studio: **File → Open**.
3. В настройках **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK** выбери **JDK 17**.
4. Дождись синхронизации Gradle и загрузки зависимостей. Проект использует Android Gradle Plugin 8.6.1, Gradle 8.7, compile SDK 35, Java 11.
5. Запусти на эмуляторе или реальном устройстве.

## Структура проекта

- `MainActivity.java` — экраны и логика работы.
- `data/HabitDb.java` — база данных SQLite, отметки, исключённые дни, расчёт прогресса.
- `ReminderReceiver.java` — уведомление и перенос ежедневного напоминания.
- `BootReceiver.java` — восстанавливает напоминание после перезагрузки устройства.
- `res/layout/activity_main.xml` — главный экран.
- `res/menu/bottom_navigation_menu.xml` — пункты нижнего меню.
- `res/drawable/` — иконки для навигации.
- `res/values/styles.xml` — тема приложения и стиль текста навигации.

## Что умеет приложение

- При первом запуске создаётся тестовая привычка «Зарядка».
- Привычки можно создавать, редактировать, менять цвет, назначать дни недели и удалять.
- Нажатие на прошедшую или текущую дату в календаре отмечает выполнение. Долгое нажатие исключает день из расчёта прогресса (как в веб-версии).
- Будущие даты отметить нельзя.
- Прогресс привычки считается с первого выполненного дня по сегодня. Исключённые дни убираются из знаменателя. Общий процент — среднее арифметическое процентов всех привычек (как `calculateProgress` / `calculateTotalProgress` в веб-версии).
- Тема и настройки напоминаний сохраняются локально.
- Напоминания используют точный будильник. На Android 12+ система может запросить разрешение на точные будильники, на Android 13+ ещё и разрешение на уведомления.

## Про русскую клавиатуру

Поле для названия привычки принимает обычный Unicode-текст и настроено как текстовое поле, а не только для английского или цифр. Языки клавиатуры берутся из настроек устройства/эмулятора. Если клавиатура показывает только английский — добавь русский в настройках клавиатуры устройства (Gboard → Языки → Добавить клавиатуру → Русский).

## Статус сборки

В архиве — исправленный исходный проект. Он **не собирался** на твоей установке Android Studio и **не тестировался** на твоём устройстве. Если Gradle выдаст ошибку — пришли полный вывод сборки, чтобы можно было точно исправить проблему с зависимостью или SDK.

## Обновление от 23.11.2026

- Дни недели, не выбранные в расписании привычки, показываются приглушёнными, не нажимаются и не учитываются в пропусках, проценте и серии.
- Добавлена иконка приложения Starting tomorrow.
- Напоминания используют точный будильник, если Android разрешил; иначе — резервный неточный, который может сработать с задержкой.
- В настройках видно состояние разрешений и есть кнопка проверки уведомления через минуту.

**Как проверить напоминание:** открой **«Настройки» → «Напоминания» → «Проверить уведомление через минуту»**. На Android 13+ разреши приложению отправлять уведомления. На Android 12+ для точного времени также разреши «Будильники и напоминания» в системных настройках приложения. Не используй «Принудительно остановить» для теста — Android отменяет будильники принудительно остановленного приложения.
